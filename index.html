Distribution Schedule

Greedy priority-queue algorithm assigns trips to highest-need localities first.

Algorithm
Priority Queue + Greedy Algorithm
Each locality receives a composite priority score computed as:
Score = (Severity x 3) + (DaysWithoutWater x 2) + (Population / 10000) + SpecialNeedsBonus
The scheduler greedily assigns the next available tanker to the highest-score locality until all tanker trips are exhausted or all localities are served.
TimeO(n log n)
SpaceO(n + m)
